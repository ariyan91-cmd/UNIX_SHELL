3. NEW CAPABILITIES ADDED
================================================================================

A. PIPE SYSTEM CALL
-------------------
Signature: int pipe(int pfd[2])
Returns: 0 on success, -1 on failure
Result: pfd[0] = read fd, pfd[1] = write fd

Example usage:
    int pfd[2];
    if (pipe(pfd) == 0) {
        write(pfd[1], "Hello", 5);
        char buf[10];
        read(pfd[0], buf, 10);
        close(pfd[0]);
        close(pfd[1]);
    }

B. INPUT REDIRECTION
--------------------
Shell syntax: cmd < inputfile

Supported in:
  - cat command (explicit support)
  - Generic command parsing (prepared for future use)

Example usage:
    > cat < file.txt
    > cat < input.txt > output.txt

C. OUTPUT REDIRECTION  
---------------------
Shell syntax: 
  - cmd > outfile (overwrite)
  - cmd >> outfile (append)

Supported commands:

Example usage:

    > cat file.txt >> output.txt

5. SYSTEM ARCHITECTURE
================================================================================

File Descriptor Types:
  FD_INODE (existing) - Regular files
  FD_PIPE (new) - Pipes
  FD_NONE - Unused

I/O System Call Flow:
  User: sys_read(fd, buf, n)
    ↓
  Syscall: sys_read(tf) - validates fd
    ↓
  File layer: file_read(f, buf, n)
    ↓
  Specific handler based on f->type:
    - FD_INODE: inode_read()
    - FD_PIPE: pipe_read()  [NEW]
    ↓
  Returns bytes read

Pipe Buffer Management:
  - 512-byte circular buffer (PIPESIZE)
  - nread, nwrite pointers track position
  - readopen/writeopen flags track state
  - Spinlock for concurrent access
  - Max 16 pipes per system (NPIPE)

  Status: By design (microkernel architecture)
  Workaround: Use spawn() for new processes

Limitation 2: Single shell instance
  Status: By design for this project
  Workaround: Internal command separation via spawn()

  Status: Can be enhanced
  Workaround: Use polling or higher-level abstractions

  Workaround: Modify programs or add new ELF binaries
