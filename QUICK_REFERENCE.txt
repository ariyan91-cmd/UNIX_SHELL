   Usage: int pfd[2]; pipe(pfd);

2. INPUT REDIRECTION
   Usage: cat < input.txt
   Effect: Reads file as input

3. OUTPUT REDIRECTION  
   Usage: cat file.txt > output.txt
   Usage: cat file.txt >> output.txt
   Effect: Writes output to file

4. UNIFIED I/O INTERFACE
   • read/write work on files, pipes, console
   • Consistent file descriptor semantics
   • UNIX-like behavior

5. PROCESS SPAWNING
   Usage: spawn <id> (1-5)
   Creates new processes with ELF binaries

  #include <syscall.h>

      write(pfd[1], "data", 4);
      char buf[10];
      read(pfd[0], buf, 10);
      close(pfd[0]);
      close(pfd[1]);
  }
