ARCHITECTURE OVERVIEW
================================================================================

System Call Flow:
  
  User Code
    ↓
  sys_pipe(pfd)  [user/include/syscall.h]
    ↓
  SYS_pipe interrupt (T_SYSCALL #48)
    ↓
  syscall_dispatch() [kern/trap/TDispatch/TDispatch.c]
    ↓
  sys_pipe(tf) [kern/fs/sysfile.c]
    ├→ pipe_alloc() → allocate pipe buffer
    ├→ file_alloc() → allocate 2 file structs
    ├→ fdalloc() → allocate 2 fds for current process
    ├→ Set FD_PIPE type and connect to pipe
    └→ Return [read_fd, write_fd]

Read/Write Flow:

  User: read(fd, buf, n)
    ↓
  sys_read() [kern/fs/sysfile.c]
    ↓
  file_read(f, buf, n) [kern/fs/file.c]
    ↓
  if (f->type == FD_PIPE)
    → pipe_read(f->pipe, buf, n) [kern/fs/pipe.c]
  else if (f->type == FD_INODE)  
    → inode_read(f->ip, buf, ...) [kern/fs/inode.c]
